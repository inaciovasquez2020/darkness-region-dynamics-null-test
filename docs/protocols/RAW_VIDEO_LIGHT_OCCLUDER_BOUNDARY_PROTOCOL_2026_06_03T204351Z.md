# Raw video protocol: light occluder boundary

Status: PROTOCOL_ONLY_RAW_VIDEO_NOT_SUPPLIED

Goal:
Record a real video of a moving light/dark boundary so the repository can later build a ConcreteTrialDatasetWithRealMeasurementsAndBaselineComparison.

Required physical setup:
1. Use a fixed camera.
2. Use a fixed light source.
3. Use a flat background with visible scale marks.
4. Move one occluder across the light path.
5. Keep the camera, light source, and background stationary.
6. Record at the highest available frame rate.
7. Save the original unedited video.

Required saved file:
data/real_measurements/raw/light_occluder_boundary_trial_001.mov

Required metadata:
data/real_measurements/metadata/light_occluder_boundary_trial_001.metadata.json

Required extracted observations:
data/real_measurements/extracted/light_occluder_boundary_trial_001.boundary_observations.csv

Boundary:
This protocol does not supply real data.
It does not establish new science.
It does not validate novelty.
